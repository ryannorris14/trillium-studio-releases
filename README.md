# Trillium Studio — Downloads

Installers for **Trillium Studio**, the Trillium Academy schedule-building app.

**→ [Download page](https://ryannorris14.github.io/trillium-studio-releases/)** (same page for first install and every update)

This repository holds only compiled installers and the download page.
The source code lives in a private repository; installers contain **no student
data of any kind** — school data is loaded from a `.trillium` file handed over
directly.
